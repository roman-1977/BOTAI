# Roadmap

Этот документ пока фиксирует направления, а не окончательный scope релизов.

## MVP — кандидат

Цель MVP:

доказать, что основной цикл BOTAI полезен пользователю.

Предварительно:

- базовая структура предметов / тем;
- загрузка готового набора;
- три основных типа заданий;
- текст, изображения и формулы;
- история ответов;
- базовый алгоритм повторений;
- ежедневная очередь;
- базовая статистика;
- локальное или облачное сохранение прогресса.

Не утверждено, должен ли BOLDAI входить в первый MVP.

## v1.0 — кандидат

Возможные функции:

- цели;
- несколько предметов;
- полноценная библиотека;
- аккаунт;
- синхронизация;
- BOLDAI;
- текстовый AI-экзамен;
- голосовой AI-экзамен;
- подробная статистика;
- недельные отчёты.

## Later

- создание публичных наборов;
- модерация;
- рейтинги;
- обновляемые версии курсов;
- авторы / преподаватели;
- родительский режим;
- группы;
- друзья;
- челленджи;
- AI-импорт PDF и фотографий;
- автоматическое создание учебного материала;
- web / Android при необходимости.

## Принцип

Не добавлять функцию в MVP только потому, что она выглядит полезной.

Каждая функция должна отвечать на вопрос:

**Нужна ли она для проверки основной продуктовой гипотезы BOTAI?**
