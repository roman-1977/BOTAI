## Утверждённый UX
Главная — светлая нейтральная, компактная, с графиком прогресса/темпа, одной основной кнопкой **БОТАТЬ**; **ПРОДОЛЖИТЬ**, если есть прерванная сессия. Не три конкурирующие кнопки! На старте занятия отдельная настройка: область (тема / предмет / несколько разделов / вперемешку), формат (карточки / тесты / смешанный), стратегия (обучение / повторение), сохранение последней конфигурации; затем «Начать». Для Learn утверждена тёмная игровая тема с HUD и встроенным Mode console, см. `docs/UI_SPEC.md`. Нельзя объявлять недоступные AI-режимы готовыми: AI-экзамен исключён из MVP. Сессия должна восстанавливаться после закрытия приложения с того же вопроса, без потери сохранённых ответов. План по дням — рекомендация, отдых не блокирует добровольное занятие.
