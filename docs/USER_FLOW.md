# Core User Flow

## Первый запуск

Пользователь отвечает на вопрос:

**Что хочешь заботать?**

Он может выбрать готовый материал из библиотеки или впоследствии создать собственный.

Затем BOTAI предлагает оформить долгосрочную цель (датированную или без даты) и отдельную дневную норму. Пользователь может принять рекомендацию или изменить её.

Пример долгосрочной цели:

- ЕГЭ;
- химия;
- дата экзамена;
- выбранный курс.

## Главный экран

Главный экран должен отвечать прежде всего на вопрос:

**Что мне делать сегодня?**

Пример:

До ЕГЭ: 251 день

Сегодня: **7 / 10 вопросов**

План BOTAI:

- повторить просроченное;
- укрепить слабое;
- добавить новое.

**БОТАТЬ** / **ПРОДОЛЖИТЬ**

Пользователь не обязан самостоятельно выбирать тему или колоду.

## Учебная сессия

Пользователь запускает один опросник или выбранный набор материалов; незавершённое занятие можно продолжить без повторного выбора. Внутри занятия набор материалов не меняется.

Сверху постоянно видны четыре дневных показателя: вопросы относительно цели, активные минуты относительно цели, правильные/неправильные ответы и охват уникальных вопросов. Цели могут быть перевыполнены.

Вопрос и ответ всегда представлены карточкой. Без вариантов карточка переворачивается и пользователь оценивает воспоминание. При одном правильном варианте результат показывается сразу после выбора; при нескольких — после кнопки **Ответить**. После проверки клик по карточке или всей области ответов переводит к следующему вопросу с анимацией карточки.

Внизу всегда доступна **Пауза**. Она прекращает текущее активное занятие на экране, но не обнуляет дневной прогресс. Время считается только во время активной работы над вопросом.

Игровая панель режима позволяет менять стратегию (**Учим / Повторяем / AI**), формат (**Карточка / Тест / AI**) и темп (**Спокойно / На скорость / AI**) со следующего вопроса. Направление пар/таблиц задаётся при создании материала и здесь не меняется.

## Готовность к проверке

После достаточного изучения темы BOTAI предлагает пройти AI-экзамен.

**БОЛТАТЬ**

## AI-экзамен

AI задаёт вопросы по изученному материалу.

Следующий вопрос может зависеть от предыдущего ответа.

При ошибке AI может уточнить проблемную область.

## Результат экзамена

Пользователь получает:

- уровень понимания;
- сильные стороны;
- слабые стороны;
- выявленные пробелы.

Основное действие после неудовлетворительного результата:

**ЗАБОТАТЬ ПРОБЕЛЫ**

## Возврат к обучению

BOTAI включает связанные с пробелами элементы в последующие занятия.

После повторения пользователь снова проходит проверку.

Цикл:

**БОТАЙ → БОЛТАЙ → ПРОБЕЛЫ → БОТАЙ → БОЛТАЙ → ЗНАЙ**

## Quiz ownership flow

Personal-first: `Library → My quizzes → Open → Start`.

Authoring: `My quizzes → Create/import → Review pairs → Save privately → Open/Start/Edit`.

Shared discovery: `Library → Shared library → Published quiz → Add to my library → Open/Start`.

Shared content is read-only. To change it: `Published quiz → Create my copy → Owned quiz → Edit`.

Publishing: `Owned quiz → Propose publication → Select course/subject/section/topic → Review → Submit`. Saving and publishing are never the same action.
