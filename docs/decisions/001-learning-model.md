# ADR-001: Separate memorization from knowledge examination

Status: Accepted

## Context

Изначально рассматривалась идея превращать каждый элемент учебного материала в сложный граф знаний и генерировать различные проверки одного знания.

В обсуждении было принято более простое продуктовое разделение.

## Decision

BOTAI разделяет два процесса.

### БОТАЙ

Запоминание заранее утверждённого материала.

### БОЛТАЙ

Отдельный AI-экзамен после изучения материала.

AI использует содержимое темы / опросника как основание для новых вопросов и проверки понимания.

## Consequences

Преимущества:

- проще авторство учебного материала;
- проще контролировать корректность;
- AI не вмешивается в этап первоначального запоминания;
- можно отдельно измерять память и понимание;
- архитектуру можно развивать постепенно.

Цикл продукта:

**БОТАЙ → БОЛТАЙ → ПРОБЕЛЫ → БОТАЙ → ЗНАЙ**
