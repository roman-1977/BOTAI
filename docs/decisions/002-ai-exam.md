# ADR-002: AI exam uses approved learning material as source

Status: Accepted conceptually

## Decision

BOLDAI не является обычной голосовой карточкой.

Это отдельный AI-экзамен.

AI получает утверждённый учебный материал темы и формирует проверку на его основании.

AI может:

- задавать новые формулировки;
- связывать известные факты;
- задавать уточняющие вопросы;
- адаптироваться к ответам пользователя;
- оценивать смысл ответа;
- выявлять пробелы.

## Constraint

По умолчанию AI не должен проверять знания, которые отсутствуют в утверждённом материале выбранной темы.

## Result

Выявленные пробелы передаются обратно в систему планирования BOTAI для повторения.
