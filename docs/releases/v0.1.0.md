# BOTAI v0.1.0 — technical baseline

**Status:** pre-refactor engineering baseline; not an App Store production release.
**Version:** 0.1.0 (build 1). **Platform:** iOS 18+.

## Included

- Local-first iOS learning app: materials, CSV/TSV and BOTAI package import/export, question generation and learning sessions.
- Card, single-choice and multiple-choice study modes in current UI.
- Courses, sections, topics, study goals, learning history and progress.
- SQLite persistence and per-account isolation; authenticated Supabase attempt sync for supported text cards, with durable outbox and historical answer snapshots.
- Development Supabase RLS safeguards and retry-safe publication of supported cards.

## Known limitations (not a public release)

- Remote publication/sync does not cover all card types, image/LaTeX content, or full multi-device pull/reconciliation.
- Some persistence errors are not surfaced in the UI; a failed database open may leave a nonpersistent store.
- Visual language, navigation, accessibility and large-text behavior require audit and refactoring.
- Automated tests are not a substitute for physical iPhone installation and acceptance testing.
- TestFlight distribution requires valid Apple signing, an App Store Connect app record and upload; GitHub tagging does not publish to TestFlight.

## Verification baseline

## Refactor policy

Tag this baseline as `v0.1.0`. Develop architecture/design refactoring in `refactor/v0.2.0`. No new product features, and preserve existing tests and user data.
