# BOTAI — подготовка материалов для импорта

## CSV / TSV
Первая строка — названия атрибутов. Каждая следующая строка — одно знание. Кодировка UTF-8. Для CSV рекомендуется разделитель `;`; TSV использует табуляцию. Названия колонок должны быть понятными пользователю: `Название`, `Формула`, `Класс`, `Схема реакции`.

После загрузки BOTAI не требует заранее превращать таблицу в тест. Пользователь создаёт наборы вопросов и указывает, какие атрибуты участвуют в шаблоне вопроса и ответов. `{1}`, `{2}` и далее соответствуют добавленным атрибутам.

Пример: `Что получится при взаимодействии {1} и {2}?`.

## CSV + изображения
Для изображений используйте ZIP. В архив положите CSV/TSV и каталог с изображениями. В ячейке таблицы укажите относительный путь, например `images/water.png`. Поддерживаемые изображения: PNG, JPG/JPEG, WebP, HEIC. Колонок с изображениями может быть несколько; давайте им содержательные имена (`Чертёж`, `График`, `Структурная формула`), поскольку эти имена отображаются в конструкторе.

Пример структуры:
`data.csv`, `images/water.png`, `images/co2.png`.

## Текст, формулы и символы
Вопросы и ответы могут быть многострочными. Перенос строки вводится обычной клавишей Return. Для часто используемых математических, физических и химических символов в редакторе есть панель символов: × ÷ ± ≈ ≠ ≤ ≥ √ π ∞ ° → ⇄ Δ Σ, верхние степени и нижние индексы.

Для простых формул предпочтителен Unicode: `H₂SO₄`, `x²`, `a ≥ b`, `Δt`, `A → B`. Полноценный LaTeX/MathJax в текущую версию пока не входит.

## Проверка перед сохранением
Разверните «Исходные данные», проверьте текст и изображения, затем создайте хотя бы один набор вопросов. В каждом наборе должен быть вопрос, минимум один ответ и минимум один правильный ответ. Блок «Пример» показывает, как шаблон выглядит на первой записи. После сохранения откройте материал и пролистайте несколько вопросов.

## Промпт для ИИ: обычный CSV
Скопируйте этот запрос в ИИ и замените описание темы:

> Подготовь учебную таблицу для BOTAI по теме «[ТЕМА]». Верни только CSV в UTF-8 с разделителем `;`. Первая строка должна содержать короткие понятные названия колонок. Одна строка = одно знание. Не объединяй несколько фактов в одной ячейке без необходимости. Не добавляй нумерацию, Markdown и пояснения вне CSV. Значения должны позволять строить вопросы в обоих направлениях. После создания проверь отсутствие пустых строк и дубликатов.

## Промпт для ИИ: CSV + изображения
> Подготовь структуру ZIP для импорта в BOTAI по теме «[ТЕМА]». Нужен файл `data.csv` в UTF-8 с разделителем `;` и папка `images/`. Одна или несколько колонок CSV могут содержать относительные пути вида `images/name.png`. Дай колонкам изображений содержательные названия, например `Чертёж`, `График` или `Структурная формула`. Не вставляй изображения внутрь CSV. Сначала выведи содержимое CSV, затем список необходимых файлов изображений с точным именем и описанием того, что должно быть изображено. Проверь, что каждый путь из CSV соответствует ровно одному файлу.

## Промпт для ИИ: предложить наборы вопросов
> Вот заголовки и несколько строк моей таблицы для BOTAI: [ВСТАВЬТЕ ДАННЫЕ]. Предложи наборы вопросов. Для каждого укажи: шаблон вопроса с `{1}`, `{2}`; какие колонки подставляются и в каком порядке; шаблон каждого ответа; используемые колонки; какой ответ правильный. Используй только данные, реально присутствующие в таблице. Отдельно предложи обратные вопросы, если они имеют учебный смысл.

## Файл .botai
Импорт `.botai` как отдельного материала был реализован как технический прототип и успешно проверил перенос данных и изображений. Продуктовое решение изменено: `.botai` будет форматом переноса **курса**, а не альтернативой CSV-импорту материала. Курс сможет включать несколько материалов, структуру и методику обучения. До фиксации Course Package v2 пользовательская инструкция на импорт `.botai` намеренно не публикуется.
